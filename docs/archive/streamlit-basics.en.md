# Streamlit Basics

## What Is Streamlit?

Streamlit is a Python framework for building interactive data apps from a single Python script. Rather than separating UI and server logic (as Shiny does), you write one script that runs top to bottom; widgets (sliders, buttons, dropdowns) are added as simple function calls. On every interaction, Streamlit reruns the script and updates the display. Typical use: quick, simple visualization and prototyping on top of Python/pandas.

## Getting Started

The best starting point is the official tutorial: [Streamlit—Get Started](https://docs.streamlit.io/get-started).
