# Share Code via GitHub

We recommend versioning your app code on [github.zhaw.ch](https://github.zhaw.ch) from the start—this makes it easy to track changes, share code with other researchers, and collaborate. Your ZHAW login is all you need to get started.

New to Git or GitHub? Here are a few starting points:

- [Git—official documentation](https://git-scm.com/doc)
- [GitHub Docs](https://docs.github.com)

Once you are ready to publish your app, we will set up a repository together under [github.zhaw.ch/service-research-data](https://github.zhaw.ch/service-research-data)—the GitHub organisation of Services Forschungsdaten. From there, the app is published to Posit Connect.
