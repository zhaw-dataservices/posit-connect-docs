### Unterstützte Versionen

Damit deine App zuverlässig läuft, sollte deine lokale R-, Python- oder Quarto-Version mit einer der auf unserem Posit-Connect-Server unterstützten Versionen übereinstimmen.

<!-- Stand: 2026-07-09, Posit Connect 2026.02.0 (unterstützt bis 31. August 2027). Bei einem Server-Update hier aktualisieren. -->

| | Unterstützte Versionen |
|---|---|
| R | 4.4.3, 4.5.3 |
| Python | 3.14.3, 3.14.4 |
| Quarto | 1.9.37 |
