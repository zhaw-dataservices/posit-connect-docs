# Best Practices

This page describes our recommendations for developing apps hosted on Posit Connect.

## Managing Dependencies

### Supported Versions

For your app to run reliably, your local R, Python, or Quarto version should match one of the versions supported on our Posit Connect server.

<!-- As of 2026-07-09, Posit Connect 2026.02.0 (supported until August 31, 2027). Update here after any server upgrade. -->

| | Supported Versions |
|---|---|
| R | 4.4.3, 4.5.3 |
| Python | 3.14.3, 3.14.4 |
| Quarto | 1.9.37 |
