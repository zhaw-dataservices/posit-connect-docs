# Shiny Basics

## Was ist Shiny?

Shiny ist ein R-Paket, mit dem sich interaktive Web-Apps direkt aus R-Code bauen lassen – ohne dass du HTML, CSS oder JavaScript schreiben musst. Eine Shiny-App besteht aus zwei Teilen: dem UI (was die Nutzer:innen sehen: Buttons, Grafiken, Tabellen) und der Server-Logik (was im Hintergrund passiert, wenn z. B. ein Filter geändert wird). Ändert jemand eine Eingabe, aktualisiert Shiny automatisch nur die betroffenen Teile der App – das nennt man reaktiv. Typischer Einsatz: interaktive Dashboards und Auswertungen auf Basis von R.
